KidsSongStudio

KidsSongStudio is a personal tool that produces original songs for children and uploads them to its owner's own YouTube channel.

It runs only on the owner's computer. It is not offered to the public, and nobody else can sign in to it.

How it uses YouTube

KidsSongStudio uses YouTube API Services to:

  • upload videos to the owner's channel and set their titles, descriptions, tags and thumbnails
  • add the videos to the owner's playlists
  • read the owner's video statistics
  • search public YouTube videos so it doesn't publish duplicate titles

Every video is marked "made for kids", and is labeled as altered or synthetic content.

By using KidsSongStudio you agree to the YouTube Terms of Service.
