▶ YouTube KidsSongStudio uses YouTube API Services

Privacy Policy

Last updated: 26 October 2026

KidsSongStudio is a personal tool. Only its owner uses it, to manage their own YouTube channel.

Use of YouTube API Services

KidsSongStudio uses YouTube API Services. By using KidsSongStudio you agree to be bound by the YouTube Terms of Service.

KidsSongStudio's use of information received from YouTube API Services is also covered by the Google Privacy Policy (https://policies.google.com/privacy).

What information it accesses

When the owner signs in with Google, KidsSongStudio gets permission to:

  • upload videos to the owner's YouTube channel
  • manage the titles, descriptions, tags, thumbnails and privacy settings of those videos
  • manage the owner's playlists
  • read the owner's channel and video information and statistics
  • search public YouTube videos

It does not request the owner's contacts, email or files.

How the information is used, stored and shared

  • Information is used only to publish and track the owner's own videos.
  • The OAuth tokens that Google issues are stored only on the owner's computer, in a file only the owner can read. They are never logged.
  • No information is sent to any server other than Google's.
  • No information is sold or shared with anyone.
  • No cookies or tracking technologies are used.

Viewers and children

KidsSongStudio collects no information from the people who watch the videos, including children. All videos are marked "made for kids" on YouTube.

Data retention and deletion

  • Stored tokens are kept only as long as the owner keeps using KidsSongStudio.
  • To revoke KidsSongStudio's access to your Google account, go to Google security settings (https://security.google.com/settings/security/permissions).
  • After access is revoked, the stored tokens stop working. Deleting the token file then erases all stored credentials.
  • Video statistics are fetched when needed and not stored. The only API data KidsSongStudio keeps is a local record of the owner's own uploads (video ID, link and upload result), which the owner can delete at any time.
  • To ask for any data to be deleted, contact the address below.
